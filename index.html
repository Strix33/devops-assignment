Core Concepts
🔄

Continuous Integration

Automatically build and test code changes every time a developer commits to the repository, catching bugs early.

🔌

Git Plugin

Jenkins Git Plugin enables direct connection to any Git-based repository (GitHub, GitLab, Bitbucket) for source checkout.

📦

Workspace

Jenkins clones your repository into a dedicated workspace directory so build steps always operate on fresh, clean code.

📜

Jenkinsfile

Pipeline-as-code approach: define your entire CI/CD pipeline in a Jenkinsfile stored alongside your source code.

🛡️

Credentials

Jenkins securely stores GitHub tokens / SSH keys so private repositories can be cloned without exposing credentials.

⚡

Webhooks

GitHub webhooks trigger Jenkins builds automatically on every push, removing the need for manual "Build Now" clicks.

Pipeline as Code
Jenkinsfile
// Declarative Pipeline – Assignment 6
pipeline {
    agent any

    environment {
        APP_NAME = 'devops-demo'
        PYTHON   = 'python'
    }

    stages {
        stage('Checkout') {
            steps {
                git branch: 'main',
                    url: 'https://github.com/Strix33/devops-assignment.git'
                echo "✅ Code checked out successfully"
            }
        }

        stage('Build') {
            steps {
                echo "🔨 Building ${env.APP_NAME}..."
                sh 'python app.py'
            }
        }

        stage('Test') {
            steps {
                echo "🧪 Running test suite..."
                sh 'python -m pytest --tb=short || python app.py'
            }
        }

        stage('Archive') {
            steps {
                echo "📦 Archiving workspace..."
                archiveArtifacts artifacts: '**/*.py,**/*.html',
                                  allowEmptyArchive: true
            }
        }
    }

    post {
        success { echo "🎉 Pipeline completed successfully!" }
        failure { echo "💥 Pipeline failed. Check console output." }
    }
}
Setup Procedure
1

Create GitHub Repository

Create a new repository on GitHub and push this project. The repo should contain app.py, index.html, Jenkinsfile, and README.md.

2

Install Jenkins Plugins

Navigate to Manage Jenkins → Plugins → Available. Install Git Plugin, GitHub Plugin, and Pipeline Plugin. Restart Jenkins after installation.

3

Create a Freestyle / Pipeline Job

Click New Item, name it GitHub-Jenkins-Demo, and select Freestyle Project or Pipeline. Click OK to proceed.

4

Configure Source Code Management

Under Source Code Management select Git, paste your repository URL, and set branch to */main. Add credentials for private repos.

5

Add Build Step

In the Build Steps section, add Execute Shell (Linux) or Execute Windows batch command and enter python app.py.

6

Build Now & Verify

Click Build Now. Open Console Output to confirm the repository is cloned and the build runs successfully.
